# DokuLap v2

Pengembangan 1–5:
1. Dokumentasi — data real dari Google Drive/Sheet, filter, preview, buka Drive, hapus.
2. Kegiatan — kegiatan real, sekolah sebagai konteks, active mode, quick capture, statistik dokumentasi.
3. Sekolah/Lokasi — CRUD sekolah, riwayat aktivitas dan dokumentasi per sekolah.
4. Dashboard — statistik dan chart dari data backend.
5. Analisis & Insight — tren bulanan, komposisi dokumentasi, jenis kegiatan, aktivitas sekolah.

UX:
- Mobile-first + bottom navigation.
- Sidebar desktop + mobile drawer.
- Skeleton/loading overlay.
- Toast success/error/warning.
- Animasi page, card, modal, chart, progress upload.
- Dark/light theme.
